What Pro adds

Response caching

Instant answers, zero cost

Moderation checks, tagging, alt text and FAQ answers are often requested again and again with identical input. Pro remembers the answer and serves it in milliseconds.

  • Turn caching on per plugin. Leave creative tools alone.

Pro questions

Will caching give my visitors stale or wrong answers?

Only identical requests are answered from the cache, and only for the plugins you turn it on for. You choose how long answers are kept. Leave caching off for tools that should give a fresh answer every time, such as content generators.

Does the cache store personal data?

No. Answers are stored before Gatehouse puts real values back, so the cache holds placeholders such as [EMAIL_1], not the personal data itself.

What happens if my license expires?

Caching switches off and requests go to your provider as normal. Nothing breaks, and the free plugin keeps working. Renew and caching turns back on. If our license server is ever unreachable, Pro keeps working for up to 14 days.

How do I install Pro?

Install the free plugin first, then upload gatehouse-pro.zip under Plugins → Add New → Upload Plugin and enter your license key under Gatehouse → Caching. Full guide.
