Privacy, security and accessibility

Privacy

Gatehouse does not send your data anywhere. It has no account, no tracking, no analytics and no “phone home”. Everything it records stays in your own WordPress database.

What is storedFor each AI call: the plugin, model, token counts, estimated cost, timing, status and the WordPress user ID if someone was logged in.
What is not storedPrompt and response text, unless you turn on debugging excerpts. Your API keys are never stored or read by Gatehouse.
RetentionCalls are deleted automatically after 90 days by default. Choose 30, 90, 180 or 365 days.
RedactionEmails, phone numbers, card numbers, IBANs, US SSNs, optional IP addresses and your own terms are replaced before a request leaves your server.

Repeated-request detection stores only a fingerprint (a one-way hash) of each request, never its text. With Pro caching, cached answers hold placeholders, not the personal data that redaction removed.

Uninstalling Gatehouse deletes its database tables, settings and scheduled tasks. Deactivating keeps them, so you can switch it back on.

Security

  • Administrators only. Every screen and every API endpoint requires the manage_options capability, and every request is protected by WordPress's own nonces.
  • No new attack surface. Gatehouse adds no public pages, forms or endpoints. It works only through WordPress's own AI Client hooks and HTTP API.
  • Your keys stay where they are. API keys remain in WordPress's Connectors. Gatehouse never reads, copies or logs them.
  • Safe database access. Every query is parameterised, so input can't be turned into SQL.
  • Safe output. The dashboard renders all data as text, never as raw HTML.
  • Fails safe. If a price download fails, the last good prices stay in use, so costs are never left without a price.
  • Reviewed. Every release passes WordPress's official Plugin Check, a security review and 245 automated tests, on PHP 7.4 through PHP 8.3.

GDPR and compliance

Gatehouse helps you meet your obligations as a data controller when your site uses AI.

  • Data minimisation: redaction keeps personal data out of requests to AI providers, and logs keep facts about calls, not their content.
  • Right of access: Tools → Export Personal Data includes a person's AI requests.
  • Right to erasure: Tools → Erase Personal Data anonymises them. Costs are kept so your budgets stay correct.
  • Transparency: Gatehouse adds a suggested paragraph to Settings → Privacy → Policy Guide for your privacy policy.
  • Storage limitation: automatic deletion after your chosen retention period.

Gatehouse doesn't replace your agreement with your AI provider about how they handle the data you send. Read your provider's data processing terms.

Accessibility

The Gatehouse dashboard is designed to meet WCAG 2.2 level AA.

  • Every screen is checked automatically with axe-core, in light and dark mode, before each release: zero issues.
  • Everything works with the keyboard. Detail panels keep focus inside until you close them with Esc.
  • Every chart has a Table view for screen readers.
  • Status is shown with text and icons, never by colour alone.
  • Text meets AA contrast in both themes, and animations stop when your system asks for reduced motion.

This website follows the same rules. If something doesn't work with your assistive technology, please tell us. We treat accessibility problems as bugs.

External services

Gatehouse can connect to one outside service, and only if you turn it on:

  • OpenRouter's public model list (openrouter.ai/api/v1/models), to keep model prices current. It's off until you turn on “Update prices automatically”. It's a plain daily download that sends no site address, user data, usage data or API keys. OpenRouter privacy policy.

Gatehouse Pro additionally contacts Lemon Squeezy to activate and validate your license key, and our update server to check for new Pro versions. These requests send your license key and site address, and nothing about your AI traffic.

Your AI calls go only to the AI provider you connected, exactly as they would without Gatehouse.

Reporting a problem

Security issues: please report them privately using GitHub's private vulnerability reporting, not in public. We'll respond as quickly as we can and credit you in the changelog if you'd like.

Accessibility and other issues: open a topic on the support forum.
